# Tarefa 16 — Auditoria e entrega final

EduTrack · Innovation Lab · Faculdade Impacta · 17/11/2026

**Situação:** Entrega local com adaptações declaradas.

## Entrega e explicação

A entrega reúne as 16 respostas, fontes, testes, evidências fictícias, referências Figma, OpenAPI, SQL existente e OpenSpec. O PR final permanece aberto para revisão. Não houve envio ao Classroom nem implantação dessas novas funcionalidades na VPS.

O OpenSpec ajudou a converter pedidos em critérios verificáveis: a busca precisava usar OR sem duplicação, e o PDF precisava permanecer privado. Esses critérios orientaram os módulos e testes antes da conclusão. A auditoria de entidades existentes evitou recriar tabelas e quebrar dados.

Limites honestos: não há projeto Xano/FlutterFlow; autenticação Gemini Code Assist institucional não foi comprovada; não foi refeito o histórico do semestre. O conjunto atual do backend passou em 200 testes, com 16 testes POSIX pulados no Windows; o frontend passou em 49 testes. Execução em SQL Server real e publicação desta entrega não foram realizadas.

As propostas antigas ainda abertas são mantidas como histórico de pendências; não foram marcadas completas somente para aparentar conformidade. Vídeos, aceitação das adaptações e entrega formal dependem do aluno/professor.
