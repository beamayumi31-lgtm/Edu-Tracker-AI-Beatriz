# Tarefa 02 — VS Code, Node.js e assistência de IA

EduTrack · Innovation Lab · Faculdade Impacta · 17/11/2026

**Situação:** Ambiente preparado; autenticação Gemini não comprovada.

## Entrega e explicação

O workspace EduTrack.code-workspace mantém frontend, backend e documentação separados. Node.js 24.19.0 e npm 11.17.0 foram verificados; o projeto exige Node >=22.13.0. Markdown All in One foi instalado; Gemini Code Assist 2.107.0 e Markdown All in One 3.6.3 foram confirmados na lista de extensões instalada; a autenticação Gemini institucional não foi comprovada.

A implementação e revisão desta entrega foram feitas com Codex. Não se apresenta essa execução como uma conversa autenticada no Gemini Code Assist. A documentação oficial do Google consultada em 17/11/2026 informa o encerramento do atendimento dos níveis individuais nessa extensão desde 18/06/2026; a disponibilidade institucional Standard/Enterprise depende da conta e da licença. Nenhuma assinatura foi contratada.

XanoScript foi substituído pelo backend Python e pelas migrações SQL, conforme decisão de arquitetura. Instalar uma extensão sem utilizar Xano não comprovaria o requisito funcional.
