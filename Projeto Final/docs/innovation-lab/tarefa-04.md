## Entrega e explicação

O equivalente ao ciclo pull → edição → push do XanoScript é o versionamento das fontes Python e migrações SQL. Foram preservadas as fontes existentes e criados módulos pequenos para progresso, busca e relatório. Git registra a diferença e permite revisão antes de uma implantação.

Fontes: edutrack/models.py, edutrack/routes.py, edutrack/academic_tools_routes.py e migrations/*.sql. A validação utiliza testes e compilação; nenhum banco real foi alterado nesta entrega.

Não há arquivos .xs nem sincronização com Xano. Essa é uma adaptação explícita, cuja aceitação cabe ao professor, e não uma evidência literal da plataforma exigida no enunciado.
