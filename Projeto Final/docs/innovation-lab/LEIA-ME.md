# EduTrack — 16 tarefas de Innovation Lab

Entrega preparada em 17/11/2026. Comece por RELATORIO_FINAL.pdf e pelas respostas tarefa-01.md a tarefa-16.md.
Os arquivos originais dos enunciados foram preservados fora do pacote público. A cópia Google Docs da tarefa 03 é uma variante de formatação, não uma 17ª tarefa.

## Decisão de arquitetura
O aluno autorizou manter SQL Server/Python e documentar as adaptações ao professor. O frontend React existente também foi preservado. Cumprimento técnico equivalente não significa aceite pedagógico automático. Consulte ADAPTACOES.md.

## Conteúdo
- 16 respostas numeradas com implementação, explicação e referências.
- evidencias/: screenshots reais da prévia, testes, OpenAPI, JSON do CRUD e PDF gerado pela API.
- assets/: SVG exportado do Figma e atribuição.
- REFERENCIAS.md: dois templates duplicados e pesquisa técnica.
- AGENTS.md: regras de trabalho e segurança.

## Como apresentar
1. Mostre o README e o PR de documentação integrado (#1).
2. Abra o PR final, que deve permanecer aberto para revisão do professor.
3. Mostre frontend, API, modelo SQL e OpenSpec no VS Code.
4. Execute a prévia descartável descrita no README do projeto para demonstrar sem usar dados reais.
5. Mostre a busca, o relatório PDF e a evidência de CRUD.

Nenhum trabalho foi entregue automaticamente no Classroom. A produção não foi atualizada por esta entrega.
