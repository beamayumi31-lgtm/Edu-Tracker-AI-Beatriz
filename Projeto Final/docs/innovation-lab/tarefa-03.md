# Tarefa 03 — Instalação e estrutura OpenSpec

EduTrack · Innovation Lab · Faculdade Impacta · 17/11/2026

**Situação:** Executado na estrutura atual.

## Entrega e explicação

A CLI local OpenSpec 1.12.0 está registrada nas dependências do frontend. O contexto está em openspec/config.yaml; specs, changes e archive organizam requisitos, propostas e encerramentos.

Foram acrescentados project.md e openspec/AGENTS.md como guias acadêmicos de compatibilidade. Esses arquivos são autorais; não se atribui sua criação automática à CLI moderna. O AGENTS.md da raiz do projeto contém os padrões de trabalho.

Na pasta edutrack-app-completo: `npm run openspec -- --version`, `npm run openspec:validate` e `npm run openspec -- list`.
